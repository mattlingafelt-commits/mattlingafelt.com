# mattlingafelt.com

Source for Matt Lingafelt's public profile and HT 930 portfolio site. Five static pages (Home, Statements, Work, Reflection, About) sharing `css/site.css` and `js/site.js`, with self-hosted fonts in `fonts/` (SIL Open Font License, see the license files there). No build step, no cookies, no trackers, no third-party requests. Security headers live in `_headers`.

Hosted on Cloudflare Pages. Pushing to `main` deploys.
